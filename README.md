# 魈的伴读书房 · 部署说明

1. 在 GitHub 新建一个仓库（例如 xiao-reader），把本文件夹里除 README 外的所有文件上传到仓库根目录。
2. 仓库 Settings → Pages → Source 选 “Deploy from a branch”，分支选 main，目录选 /(root)，保存。
3. 等一两分钟，得到 https://你的用户名.github.io/xiao-reader/ 。
4. 在 iPad 的 Safari 中打开该网址 → 点分享按钮 → 「添加到主屏幕」。之后从主屏幕图标打开，就是全屏的独立应用。
5. 打开「设置」，填入你的 Anthropic API Key，回到书架导入 EPUB。

注意
- 书、笔记、讨论都存在这台 iPad 的本地，请务必用主屏幕图标打开，并定期在「笔记」页导出 Markdown 备份。
- API Key 只保存在本机，请不要把仓库做成含 Key 的版本。
- 更新网页后，如果 iPad 上没变化，关掉应用重新打开一两次即可。
