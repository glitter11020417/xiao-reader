# 魈的伴读书房 · 部署说明

需要上传到 GitHub 仓库根目录的文件（更新时同名覆盖即可）：
index.html、sw.js、manifest.webmanifest、epub.min.js、jszip.min.js、icon-180.png、icon-192.png、icon-512.png

1. 仓库 Settings → Pages → Deploy from a branch → main → /(root)。
2. 网址：https://你的用户名.github.io/仓库名/
3. iPad 的 Safari 打开网址 → 分享 → 添加到主屏幕。
4. 设置页：添加接口（预设里选或自己填地址）→ 填 Key → 拉取模型 → 测试对话 → 在「用途」里选批注和讨论用的接口与模型。

注意：书、笔记、API Key 都只存在这台设备的浏览器里，请定期在「笔记」页导出 Markdown。
